# 颜色、密度与字体系统

## 当前用户约定

普通科研内容页采用高信息密度、充分使用可用版面。默认色系依据本次用户认可的第二张图。颜色角色可由截图重复像素核对，字体、比例、透明度和阴影参数为可调整制作值。

可读取[样式参数JSON](../assets/style-tokens.json)，对照[认可样例](../assets/user-preferences/approved-blue.png)。[第一张样例](../assets/user-preferences/rejected-teal.png)用于核对用户指出的青蓝配色和空白问题，其中几何示意及符号表结构仍收录在R35中。

## 蓝色角色固定映射

| 角色 | 固定色值 | 使用位置 |
| --- | --- | --- |
| 标题深蓝 | `#071B50` | 页标题、核心句、主解释、结论普通部分 |
| 主蓝 | `#0865CE` | 分区条、任务签、箭头、重要短标签、表头、标题横线 |
| 标识浅蓝 | `#7DBBFF` | 多斜杠标识第二层、渐变中间节点 |
| 标识更浅蓝 | `#B5D9FF` | 多斜杠标识第三层、次层示意 |
| 强调红 | `#A83837` | 关键需求、瓶颈、机制及结论关键词 |
| 辅助文字 | `#516278` | 图旁次说明、限定条件、来源 |
| 结论浅底 | `#E9F2FA` | 底部结论带、归纳区 |
| 标签浅底 | `#EDF4FB` | 编号条、次层标题和浅色模块 |
| 分割线 | `#DDE7F0` | 图组外框、列间线、细表线 |
| 页面白 | `#FFFFFF` | 页面、科学图底与沟槽 |

色值来自认可截图中的常见精确RGB像素及相应区域，属于截图取样。默认主色禁止回退为旧方案的`#124F78`、`#086CA8`、`#123F75`。原33图偏青蓝统一映射到本表。科研图片、热图和曲线的颜色保留原有科学含义。正文可用标题深蓝或接近黑色，同一颜色角色一致。强调色通常突出1—3处短语或一个关键阶段。

## 可选择的主题变体

- **B1 标准蓝白**。深蓝页题、主蓝分区条、浅蓝编号条、浅底结论，直接对应认可样例。
- **B2 蓝色通栏页眉**。沿用R24—R26、R30—R33通栏结构，页眉填主蓝或标题深蓝，白字；主体按本表着色。
- **B3 蓝色轻渐变**。题签或大箭头由主蓝向浅蓝/透明过渡，正文与科学图保持高对比。
- **P1 紫色备选**。仅在用户选择R11、R27—R29原色或已有汇报明确以紫色为主题时使用。深紫`#4A155E`、模块紫`#78239A`、浅紫`#F5F0F7`、分割`#DED6E4`，深紫底短标签可配暖黄`#F4D462`。所选主题整套一致。

## 高密度版面合同

分母为页眉下方、左右内容边界以内的可用区。每个占用区域必须包含实际图证、公式、关系、解释或有内容的表格。按布局语义包络估计，有效区域通常覆盖90%—95%，未分配空间约5%—10%。这组数值是设计检查目标。整体空白像素比例、巨型底色矩形面积和图片框面积不直接代表有效信息密度。

- 外边距起点为页宽2.5%—3.3%。主沟槽约页宽0.6%—1.2%，组内间隔通常0.04—0.10英寸。
- 页眉约页高8%—11%，核心句需要时约6%—10%，底结论可约6%—8%。主体使用剩余最大面积；各区实际高度合计匹配页面。
- 图、公式、表格或矩阵尽量铺至底结论上方。各区顶、底、左右边界受同一栅格约束。
- 单个未解释空洞宽达可用区16%且高达18%时触发人工复核。检查是否缺图组、变量说明、约束映射或对应结果。必要沟槽、上下标空间及图内坐标空域按含义判断。
- 图少时裁掉文件内部无信息白边，放大核心对象，再用已有资料补局部放大、图旁标注、符号/维度表、条件框、处理关系及局部结论。
- 图多时按对象、变量、阶段或证据角色分簇，采用共享图例、连续题签、相邻短说明和统一基线。
- 检查面板内部空洞。大边框配小图、宽表配稀疏单元格、内容整体集中在中央均需重排。
- 资料量不足时选择更适合的方案并扩大证据与关系，额外解释保持资料范围。无法补足的资料在交付中说明。

结果和机制页可用约60%—75%图示；背景、表格和公式页按实际结构分配。高密度通过真实图文及关系充实实现，保持必要阅读间隔。

## 字体、字号和数学

中文默认已安装微软雅黑、思源黑体或模板字体。标题700，核心句和模块600—700，正文400—600。主要层级3—4档，行距起点1.0—1.15倍，段距压紧并保留分组。

| 元素 | 常规16:9建议 |
| --- | --- |
| 页标题 | 28—34pt |
| 核心句、区域题头 | 18—22pt |
| 正文、表格、短标签 | 16—20pt |
| 就近图注和次说明 | 13—16pt |
| 来源与脚注 | 10—12pt，结合显示检查 |
| 独立公式 | 20—26pt，矩阵约18—24pt并按结构增高 |

高密度优先通过布局、分组和解释对应实现，缩字后复查实际渲染。公式使用原生公式编辑器对象，详见[公式规范](equations.md)。左右留足括号、编号和符号空间。

## 透明、边界和立体层次

透明度T为0%不透明、100%透明，程序opacity=1−T/100。正文通常T=0%。渐变箭头尾部可T=90%—100%，头部T=0%—15%，中部T=40%—60%。面板优先固定浅底。阴影起点灰黑T=80%—90%、模糊4—7pt、距离1—2.5pt。按[组件菜单](component-options.md)选择具体效果。

分割线0.5—0.8pt，页题横线0.7—1.2pt。题签可轻盖面板边缘，阴影控制在组级。参数集中设置并渲染确认。
