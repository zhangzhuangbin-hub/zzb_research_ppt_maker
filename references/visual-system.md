# 字体、颜色、透明度与密度

## 依据与参数边界

33张参考图包含蓝色、紫色、深蓝加红色等体系，优秀版本共同保持浅背景、明确主色、深色正文、少量重点色。多数紧凑图组页有分区条、局部解释和归纳语句。部分页为方法、表格、计划或研究基础，信息比例随任务变化。

截图可用于观察配色角色与结构，无法精确还原原PPT字号、阴影和渐变数值。以下数值为制作起点，用户明确规定的居中、图形和文件约定优先执行。

## 主题A 蓝白与暗红

适合大部分中文科研、工程、组会和项目评审，参考01—10、12—26、30—33。

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 章节标题与主框架 | `#124F78` | 页标题、主线与总框架 |
| 模块蓝 | `#086CA8` | 题签、步骤、节点 |
| 深蓝带 | `#123F75` | 通栏页眉或归纳带 |
| 正文 | `#18232B` | 说明、图注、表格文字 |
| 次要文字 | `#536675` | 辅助说明与来源 |
| 浅底 | `#F3F7F9` | 模块底、次层区域 |
| 灰色分割 | `#D9E1E7` | 分隔线和行边界 |
| 主框灰蓝 | `#B6C5CF` | 包含框、图组外边 |
| 暗红重点 | `#8C2530` | 关键问题、机制和局部结论 |
| 页面 | `#FFFFFF` | 背景 |

红色一般只突出关键词或一个关键步骤。相同颜色表达相同层级或意义，科学图表原有编码与图例保持一致。

## 主题B 紫白与少量暖色

参考11、27—29。适用于用户选择相应参考或已有汇报以紫色为主的情况。一套汇报主体色系统一。

| 角色 | 色值 |
| --- | --- |
| 深紫结构 | `#4A155E` |
| 模块紫 | `#78239A` |
| 浅紫底 | `#F5F0F7` |
| 灰色分割 | `#DED6E4` |
| 暗红强调 | `#90232B` |
| 暖黄短标签文字 | `#F4D462`，置于深紫底 |
| 正文和页底 | 延用深灰与白色 |

紫色或蓝色都可形成所选科研风格。主题由现有汇报、用户偏好及图像编码决定，避免把某一种颜色视为科研汇报的统一要求。

## 字体与字号

默认使用实际安装的微软雅黑、思源黑体或用户指定中文无衬线字体。正文常规400，分区可600，标题常用700。英文字母、数学符号、上下标和中文基线协调，特殊字体仅用于科学记号所需部分。

| 元素 | 建议起点 |
| --- | --- |
| 页面标题 | 28—34pt |
| 核心句 | 18—22pt |
| 大区标题 | 19—23pt |
| 正文、表格与标签 | 16—20pt |
| 图旁注释 | 14—17pt |
| 来源与必要脚注 | 11—13pt，结合显示距离检查 |

主要字号层级通常3—4档，正文行距常用1.05—1.2倍。核心句可两行，保持齐整。长句先精炼，再调整区域。关键科学图内部标注过小时，拆图、放大或重建必要标注。

同级标签保持同字号、字重与文字边距。标题前图形和标题共用稳定基线。符号、勾选或方框应使用可渲染的字体或原生矢量形。

## 透明度与对比

统一以PowerPoint透明度T记录，0%不透明，100%透明。绘图代码opacity=1−T/100。

- 正文、标题和必要图注通常T=0%。
- 浅底可选直接浅色T=0%，或主色T=93%—97%叠白底。
- 渐变透明箭头可从尾部T=90%—100%过渡到头部T=0%—15%。
- 低强度外阴影可从灰黑T=80%—90%起稿。

详见[组件规范](components.md)。这些数值为可实施建议，需通过实际PPT渲染检查。

## 栅格、边界和面积分配

常规16:9页外边距约页宽3%—4%，大区间距约1%—2%。标题区约页高7%—10%，核心句约8%—14%，主体按任务约65%—75%。并非所有页面都需要独立核心句和底部结论。

分割线、主面板、题签和表格对齐共同的左右边界。同组图片上边、底边或图注基线按阅读需要统一。主辅分区可非等宽，同级比较图保持可比尺度。

文图比例按页眉以下内容区的语义包络估计。图示包括机制、流程、结构、图表及照片，图内文字不重复计算。独立文字包括图外说明、核心句与结论。

- 常用起点约60%图示、30%独立文字、10%空白。
- 图示约50%—65%、文字约25%—35%、空白约8%—15%为可调范围，组合接近100%。
- 背景与概念页可给文字35%—45%，表格页优先保证数据与条件可读，结果组图可给图更多面积。
- 背景色块、阴影和装饰箭头不作为科研图证。图片包络占比与语义图文比例分别判断。

密度通过分组、对齐、层级和就近说明管理。检查整页的读图顺序，主图是否明确，图内必要信息是否可读，次要说明是否过多。
