# 页面验收与改稿

## 当前用户要求优先检查

- **逐图选择**。记录R编号和组合组件，查看对应截图。所选独特结构、局部图文和变体可辨认。
- **固定配色**。标题`#071B50`、主蓝`#0865CE`、强调红`#A83837`、浅底`#E9F2FA`/`#EDF4FB`。旧青蓝主色出现时定位并映射，科研图色标单独判断。
- **高密度**。普通内容页有效图文区域包络以90%—95%可用区为起点，检查边缘、面板内和图片内空白。宽达16%且高达18%的未解释空区触发重排并人工确认用途。
- **充实方式**。扩大证据、裁无信息白边、补资料支持的条件/变量/符号说明、局部放大和关系。检查大色块、空框是否掩盖内容稀疏。
- **公式编辑器**。源式逐符号核对；实际PPT可点入编辑；150%—200%检查分式、矩阵、上下标、括号、编号、裁切和缺字；重开后原生数学对象保留。

## 必须检查的结果

| 项目 | 可观察标准 |
| --- | --- |
| 论证 | 一个清楚问题，图证和结论对应，因果及关系方向准确 |
| 来源 | 真实数据可追溯，条件和单位完整，预测与示意有标识 |
| 页眉 | 标题前固定图形一致，标题基线稳定，横线覆盖内容宽度 |
| 字体 | 字体可用，同级大小与字重一致，正文及图注可读 |
| 配色 | 主色统一，重点色含义明确，保留科学图例 |
| 渐变透明 | 方向服务读图，透明度口径正确，文字清楚 |
| 图形 | 题签、圆角框、对话框、虚线边界各有用途 |
| 箭头 | 每条关系可解释，带字箭头文字居中，尖端正确且避开图文 |
| 项目标识 | 勾选、方框、箭头、编号按内容角色使用，同级一致 |
| 分割 | 浅灰线与浅底清楚，起止及主面板边界对齐 |
| 图组 | 主次明确，图注就近，科学对象、坐标和图例完整 |
| 层次 | 轻阴影与组合适度，图组和内层标签归属清楚 |
| 表格 | 原生文字和数据水平及垂直居中，单位、精度、内边距统一 |
| 编辑 | 一行文案为完整对象，标签和箭头带字保持整体可移 |
| 文件 | 新增／修改位置正确，用户的最新文件得到使用 |

渲染实际PPT后查看整页与关键局部。修复裁图、溢出、断行、失去语义的箭头、不可读标注或修改范围错误，再复查对应项。

## 风格复核

挑选同类参考页对照，检查本页是否具有统领句、明确分区、有作用的图证、局部解释和可识别落点。照片、机制图、曲线、表格、标签和关系按实际内容组织，主体布局可变化。

出现图像散落时重组图证簇。读图顺序不清时调整标题层级、图注和关系。信息过密时先重组、去重复、调整区域并共享图例，保留必要条件和证据。图形效果较多时检查各组件的语义和统一参数。

## 自动辅助

运行`python scripts/audit_pptx.py <file.pptx> --output report.json`可报告页数、对象数量、图片包络占比、小字号、单字对象、越界、渐变、透明与阴影对象、虚线对象、公式对象、旧主题色疑点和表格对齐线索。

自动报告不渲染、不识别图片内部文字，也不能判断论证或审美。图片包络占比不等于语义图文占比，形状组合的框架同样是有效图示。未显式写入XML的属性可能继承主题，疑点以实际软件渲染确认。

质量优先修复论证、数据和可读性，再检查视觉细节。用户确认逻辑后，视觉修改保留研究内容与证据边界。
