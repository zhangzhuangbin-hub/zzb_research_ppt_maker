# 图形、渐变、透明度与表格组件

## 参数口径

具体变体见[组件菜单](component-options.md)，页眉、题签、箭头、图组和结论可组合。蓝色统一为主蓝`#0865CE`、标题深蓝`#071B50`、浅底`#E9F2FA`/`#EDF4FB`、分割`#DDE7F0`、强调红`#A83837`。原图偏青蓝映射至该主题。

下列数值用于常规16:9汇报的起稿，是根据用户要求及截图风格选择的设计参数。压缩截图无法准确还原原PPT的透明度、渐变节点、阴影参数或字号。区分截图可见的外观与制作建议。

透明度T采用PowerPoint口径。T=0%完全不透明，T=100%完全透明。opacity=1−T/100。比如T=85%对应opacity=0.15。文本常用T=0%，渐变与透明度主要作用于背景、箭头和阴影。

## C01 固定页标题与贯穿横线

标题前可选两个叠方块、短竖条或双折角。全套用同一种形状，在固定页眉区域保持同尺寸、同基线。常规起点为标识高0.18—0.25英寸，标题与标识间距0.08—0.12英寸。

页标题下画0.7—1.2pt主色细线，连接左右内容边界。现有模板可采用通栏深色页眉加白字标题。标题与线、正文区之间留出稳定间距。标题前标识、标题和线不覆盖学校标志或真实信息。

参考04—05、08—10、24—26、30—33。第三方模板LOGO只用于观察其位置，不带入用户汇报。

## C02 梯形题签与箭头形标题

横向模块标题适合矩形加斜切边、梯形、六边形短签或右箭头形。可用深蓝到中蓝的轻渐变，白字居中，左右保留约0.08英寸内边距。标签略微覆盖主框上边缘时，保证遮盖部分的层次有意且不碰正文。

短题签可高0.28—0.36英寸，通常19—22pt。长模块名扩宽题签或分区，避免压扁字体。题签与面板编组。

参考13—19、28、31—33。梯形表达标题归属，带方向的箭头形表达路径时需有相应关系。

## C03 圆角标签与带编号标识

圆角矩形适合“输入／优化／验证”等短阶段名，胶囊适合模块名。蓝底白字或浅底深蓝字，两套择一作为同级样式。编号圈适合图旁逐项机制解释。

圆角适度，标签内的完整文字为一个文本对象。优先用AutoShape内文本，水平和垂直居中。独立底框与文本必须编组，以整体移动。

参考01、06、07、22、24—26。

## C04 矩形渐变背景与透明关系带

分区标签可用从左侧中蓝到右侧浅蓝或透明的线性渐变。正文区域可用从浅蓝到白的渐变来提示归属。一般正文底保持较浅，原图有白边时让图的外边与底色自然衔接。

| 用途 | 起稿节点和方向 |
| --- | --- |
| 标签带 | 左端主蓝T=0%，右端浅蓝T=5%—20% |
| 淡化到正文 | 左端主蓝T=0%—10%，右端同色T=95%—100% |
| 面板浅底 | 浅蓝或浅灰T=0%；也可主蓝T=93%—97%铺白底 |
| 重点短语底 | 暗红T=92%—96%，文字使用不透明暗红 |

渐变方向要与读图方向一致。关键文字放在对比足够的区域。文字本身保持高对比，不随背景渐变淡出。

参考04、06、12—15、23。

## C05 渐变透明箭头与带字箭头

跨区转换、机制引导、需求汇聚适合较宽的块箭头。为突出指向区域，可以让尾部T=90%—100%，中部T=40%—60%，箭头头部T=0%—15%；若读图方向需要另一种突出方式，可反向设置并保持同类关系一致。

带字箭头将操作名置于箭身的稳定不透明区。箭身足够长宽时用形状内文字；外置文字时与箭头编组，居中对齐。文字使用深色或白色T=0%，避开淡出的尾部与三角箭头尖端。

步骤序列可用若干首尾衔接的chevron形，关键步骤用强调色。不同模块各自有局部机制时，用细连接符表达依赖，减少大箭头抢占证据图面积。

参考01—03、08—10、15、18、20、28、33。单个箭头优先一个原生对象，细箭头使用线和箭头端一体的连接符。

## C06 虚线矩形、包含边界与约束括号

虚线矩形适合圈定输入集合、预处理、模块子过程或待研究范围。可设置无填充或极浅填充，边框0.6—0.9pt、中等灰蓝，实线外框与虚线内部各有语义。相邻模块的框线对齐，不让一个虚线边同时切过文本与图像。

横向括号或汇聚支线适合多任务共同需求，括号旁写关系名。反馈回路可用折线或弧形连接符，并标明调整对象。框与箭头的方向必须与数据流、约束或论证方向一致。

参考07、12、14、17、33。

## C07 对话框、主题引出与图旁注释

顶部核心问题可置于扁平对话框或底部带小缺口的矩形中，用小尖角指向相关模块。图旁局部放大可用细边框与短引线连接。尾部指向具体对象，避免只作为装饰。

对话框常用白或浅灰底、浅灰边线，必要时低强度阴影。框内文本保持1—2行，长解释移入主体；一页核心对话框常用一个，其他注释按需要设置。

参考02、04、08—10、21。

## C08 轻阴影与组合层次

主图组或核心面板可以使用外阴影，建议起点为灰黑色T=80%—90%、模糊4—7pt、距离1—2.5pt、方向约45°。同页同级面板用同样阴影，内层小标签通常不再重复加阴影。

浅底面板、细边框、略覆盖边缘的题签和轻阴影组合可表达前后层次。科学曲线、坐标轴、图例与主要正文保持清楚，避免阴影影响数据含义。

参考04、08—10、11、21—22。截图中的立体感可见，具体参数是制作起点。

## C09 项目标识与列举

| 内容 | 建议标识 | 排列 |
| --- | --- | --- |
| 已完成、满足条件 | 勾选✓ | 同基线，正文前留稳定间距 |
| 待做任务、考核项 | 空方框□ | 相同尺寸和左缩进 |
| 行动或推导 | 小箭头、纸飞机状箭头、双折角 | 同层采用一种样式 |
| 机制说明或步骤 | 数字圆圈、短编号标签 | 与对应图或步骤顺序一致 |
| 普通并列事实 | 实心小方块或圆点 | 一般2—4项，按实际内容调整 |

标识不承担需要口述才能理解的额外含义。纸飞机状标识采用简洁矢量形或箭头，不用与主题无关的彩色emoji。使用字体符号时检查字体支持，渲染异常则改为原生矢量。文本框内使用原生项目符号时保留悬挂缩进。

参考04、07、12—15、24—26、30。

## C10 浅色分割与边界对齐

分割线使用`#DDE7F0`，宽0.5—0.8pt。浅底使用`#E9F2FA`或`#EDF4FB`。主沟槽参考页宽0.6%—1.2%。深色边界用于主框或必要标题层级。分割线起止、面板外边、图片框、标题条与表格边界对齐到同一栅格。

对齐对象包括共同左边、右边、顶部、底部、文字基线、图注行高、列宽和内边距。按科学含义保留主次尺寸，同级图组再统一外框。容器内的图像保持比例。

参考09、12、17、20—23、25。

## C11 原生表格与数据图

表格优先原生Table。表头、正文、数据默认水平居中与垂直居中，用户另有要求时依其要求。蓝色深表头配白字，正文白或极浅灰蓝，行线浅灰、细且统一。单元格内留合理边距，行高容纳完整文字。

说明过长时精炼短语、调整列宽与行高，保留必要条件。单位在表头统一写出，小数位按比较精度统一；未知值用明确标记，脚注与数据来源置于表下。科学数据不因居中、四舍五入或美化发生变化。

统计图使用真实数据绘制，保留坐标、单位、图例和预测标识。同尺度比较，共享颜色含义，视觉强调限定到一两项关键结果。

参考12、18—19、26。表头深蓝和浅分隔可见，居中是用户明确指定规则。
