# 七组参考图的具体分析

## 来源与观察口径

本文件分析用户截图下半部的优秀版本。`../assets/reference-cases/`保留七对before/after原比例裁剪，不修补截图文字、不替换原图、不将低清截图当作可读科研证据。

共同变化是将散落材料重组为有主次的研究结构。标题条、框线、箭头和强调词帮助识别关系，较高的密度通过分组消化。

下述图文比例是人工视觉估计，以页眉以下内容区为分母。图示含结构、流程、机制、数据图，嵌入文字不重复计数；不是逐像素测量，也不是作者声明。

## 案例01　制备过程与器件结构

查看`case-01-after.png`，对照`case-01-before.png`。

- 顶部章节标题、细线、关键制备标签及两行统领句限定问题。
- 中央最大机制图承担主证据，上方预处理分到三种操作，形成总分结构。
- 左侧端面—超构表面—后处理，右侧精准制备—精准集成—制备质量，构成两条纵向链。
- “系统／器件”侧标定义层次，粗箭头表达汇入方向。图下注释贴近子图，红色强调关键加工点和验证任务。
- 内容区图与图示约60%—70%，独立文字约20%—30%。

可复用为“主机制图＋外围制备或验证链”。主图最大，两侧窄带只放短过程，避免等分。

## 案例02　材料定制与应用路线

查看`case-02-after.png`。

- 顶部“实现路径”统领句说明材料属性如何服务光调控。
- 主体上下两层。上层长横箭头串联材料定制、结构图和场景验证。
- 下层将模块、自组装、功能配体与最终结构按方向组合，右侧竖向标签概括输出。
- 短说明嵌入对应区域，图间距离、箭头与框线共同呈现关系。
- 图示约55%—65%，独立文字约25%—35%。

可复用为“上下双层路线”，适合两个相关阶段或尺度；不凭空将阶段对应画成因果。

## 案例03　成果、机制和性能证据

查看`case-03-after.png`。

- 顶部研究体系说明对象与贡献。
- 主体非等宽三块，中央较窄的核心成果是组织轴，左侧性能，右侧机制或反应证据。
- 图组保留子图关系，解释靠近对应图组，不集中堆在整页底部。
- 右侧箭头与局部说明连接表征及关键反应，短语收束贡献。
- 证据图约55%—65%，文字与标签约25%—35%。

可复用为“中心成果＋双侧证据”。需要实际性能、结构或机制资料，装饰渲染不能替代实验图。

## 案例04　背景的分类与研究缺口

查看`case-04-after.png`。

- 顶部两行区域背景限定研究范围，暗红强调对象与现实事实。
- 主体左窄右宽，左侧类型分类＋剖面示意，右侧上下为已有技术与灾害事实。
- 右侧中间突出尚未解决的定量关系，承接上下材料。
- 照片是右下证据带，分类、示意、事实和问题各有位置。
- 图示与照片约40%—55%，独立文字约35%—45%，背景页可比机制页文字更多。

可复用为“分类示意＋已有能力／现实事实＋中间缺口”。缺口需由材料推出，避免泛泛写意义重大。

## 案例05　动力学模拟的多证据组织

查看`case-05-after.png`。

- 优秀版本标题为“3.2 地幔动力学模拟”，顶部一句话给出方法与问题。
- 主体将模型示意、曲线及机制图按不同权重组成图证簇。
- 底部三条编号任务成行，解释研究变量和图证之间的对应。
- 蓝色定义模块，红色标物理机制和变量。
- 图像约55%—65%，独立文字约25%—35%。

注意上半页是“5.1 预期成果”，与下半页主题和材料不同，不能当作同样内容仅美化的对照。只提炼优秀版的组织方式，不声称保留了上半页全部内容。

可复用为“模型／曲线／机制拼图＋任务索引”，每图须有明确作用。

## 案例06　总体框架与局部机制

查看`case-06-after.png`。

- 页眉后“研究内容”标签与一句话定义主题。
- 通栏蓝色短句说明待突破问题，成为第二层视觉锚点。
- 上层为方法总框架，右侧为输出或效果；下层左侧为曲线与示意，中部为三个机制模块及作用说明。
- “多尺度编码／自适应融合／联合优化”胶囊标签与解释逐行对齐，具体说明模块做什么。
- 右侧结果短语与方法用边界和箭头连接，分组、字号与标签共同建立层次。
- 图示约50%—60%，独立文字约30%—40%。

可复用为“总框架＋局部机制＋效果”。主流程最大，局部解释为次层，效果可置于窄侧栏。

## 案例07　左侧推导与右侧两层证据

查看`case-07-after.png`。

- 顶部核心句给出场景、所用信息与目标。
- 左约40%宽，为输入—先验—约束—重建流程。虚线框限定先验构建，右括号说明与神经场的关系。
- 右约60%宽，上层先验提取、下层优化验证，每层含两张相关图及短标题。
- 暗红强调目标、先验或关键限制，蓝色构建模块层级。
- 图示约55%—65%，独立文字约25%—35%。

可复用为“左流程＋右双层证据”，适合输入较多、需解释模块作用与验证路径的算法页。

## 从案例提炼制作决策

| 观察 | 决策 |
| --- | --- |
| 密度提高，分区明确 | 组织成2—4个语义大区并保留局部分组 |
| 有主图或主流程 | 按作用分配大小，辅助图围绕论证 |
| 标签与解释贴近图 | 就近标对象、作用、结果 |
| 顶部有统领句或问题 | 先限定本页，再展开图证 |
| 框、侧标、箭头分工 | 表达模块、阶段、包含及方向 |
| 蓝色结构、红色重点 | 颜色与含义绑定，少量重复 |
| 主体因内容变化 | 不固定三栏，不机械等大 |

截图中的小字号、低清图、渐变、立体箭头和第三方标识并不都适合照搬。复制其层次和组织，交付时使用清晰图源、可读字号及用户自己的模板元素。
