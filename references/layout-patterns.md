# 科研汇报版式库

## 独立方案优先

本文件用于定位结构类别。实际制作读取[逐图独立方案库](reference-recipes.md)选定R卡及截图，保留各自分区、题签、图组、文字、关系和变体。R01—R33覆盖全部原参考，R34为认可的CAD需求页，R35为几何示意与数学符号表页。机器版位于`../assets/layout-recipes.json`。

再从[组件菜单](component-options.md)独立选择H页眉、T题签、A关系、G图组、N解释、F结论与D层次，按[视觉系统](visual-system.md)制作。页面规格记录R编号和组件编号，密度不足时调整方案与证据组织。

## 选择方法

先确定论证关系，再参考相应样例。读图顺序、主次和内容分组决定版式，图片数量作为资源条件。每页保留一个清楚的落点，多个关系可嵌套。

| 版式 | 适用页面 | 主体组织 | 样例 |
| --- | --- | --- | --- |
| 主机制＋外围链 | 制备、集成、系统组成 | 中央主图，两侧窄流程，上方总分结构 | 01 |
| 上下双层路线 | 材料到器件、两个阶段 | 上层横路径，下层模块展开，竖签说明阶段 | 02 |
| 中心成果＋双侧证据 | 成果汇报、机制与性能 | 核心成果居中较窄，左右证据簇依权重分配 | 03、11 |
| 分类示意＋研究缺口 | 背景、必要性 | 一侧概念示意，另一侧技术、事实和缺口 | 04、23、30 |
| 主模型＋证据拼图 | 模拟、多变量研究 | 主模型与相关图组，编号研究任务收束 | 05、19 |

## 关系图的语法

| 关系 | 组件选择 |
| --- | --- |
| 并列 | 同级标题与对齐分区 |
| 顺序或数据流 | 原生有向连接符或带字箭头 |
| 包含或子系统 | 细实线／虚线矩形，标清范围 |
| 约束 | 带动词的引线、括号或定向连接 |
| 汇聚 | 多分支连至共同节点或横带 |
| 对比 | 共用尺度、基线和对应标签 |
| 反馈 | 回路箭头并标调整对象 |
| 循环协同 | 圆形节点与弧形箭头，注明每个阶段 |
| 证据支持 | 图旁解释或“说明／支持”等关系，结论限定在数据范围 |

## 研究必要性页的方向

若解释电池CAD模型获取的必要性，可以从仿真、规划、现场操作任务出发，分别提出外形尺寸、空间关系和当前结构需求，汇聚到与实物匹配的工程几何表达，再说明本课题选择获取或重建CAD。

连接关系、装配约束与状态信息在相应任务中另行提供。并列任务之间不凭空添加必然先后关系。用户确认过的论证链在风格改版中保留。

## 图少和图多时

两张图可各承载机制与证据，通过标签和箭头形成协同关系。三张图可有主辅，不必等宽。四张以上按研究对象、阶段、变量或证据层次分成图证簇。原图密集时检查子图、图例与文字的最小可读尺寸。

图数量增加时，先明确每张图的作用，再调整大小、组间距和说明位置。为每个图证簇保留就近解释，删除重复陈述需保持研究信息完整。
