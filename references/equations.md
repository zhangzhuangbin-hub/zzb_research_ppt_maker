# 原生公式编辑、排版与验收

## 用户要求

科研公式使用PowerPoint可编辑的公式编辑器对象。公式采用完整数学结构，保持清晰、完整和正确。输入的LaTeX或UnicodeMath在转换后应显示为专业排版公式；独立公式、表格中的维度表达和图旁数学约束同样适用。

## 制作路径

### 在PowerPoint中编辑

1. 在目标位置插入原生公式对象，使用公式编辑器输入或转换源公式。
2. 切换专业格式并核对结构。将分式、根式、上下标、矩阵、括号、求和/积分、函数及多行对齐保持为数学结构。
3. 数学字体优先Cambria Math或已验证的Office兼容数学字体。中文解释放在就近文本框，数学变量与中文保持基线和间距。
4. 配置公式区尺寸，再调整字体和行距。多行按等号或运算符对齐，公式编号置于独立右对齐对象并编组。
5. 保存，重新打开，点入公式编辑，并检查实际渲染。

### 程序化生成

先确定当前演示工具是否支持原生Office数学。具备支持时，写入Office Math / OMML结构并保留公式对象。输出后必须由实际PowerPoint打开和渲染确认。

PowerPoint的DrawingML数学容器为`a14:m`，段落中的直接数学内容为`m:oMath`或`m:oMathPara`。Office扩展使用`mc:AlternateContent`兼容机制。代码写包时按官方结构使用命名空间、兼容选择和回退，同时保留原生数学分支。Word的OMML用于PowerPoint时，移除WordprocessingML子元素，并检查PowerPoint不允许的矩阵/公式行距属性。上述结构边界见[微软DrawingML数学规范](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-odrawxml/853b19c7-68a9-4f9a-a2ae-5e6cb0d02e62)与[TextMath说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.office2010.drawing.textmath?view=openxml-3.0.1)。

具备MathML→OMML转换器时，可先转换再按DrawingML限制适配。转换器路径和Office可用性在当前环境检测，使用相对可迁移脚本或环境发现机制。自动转换结果需要逐式核对，特别是矩阵、长括号、分段函数和中文数学混排。

技能内`assets/equation-examples/`提供经过本机PowerPoint打开、保存、渲染后的4个数学容器示例，覆盖分式、矩阵、求和上下限和根式，可用于核对XML结构。具体公式必须按源式构建，插入后仍需逐项验收。

当选定工具不能建立原生公式时，应更换为支持公式编辑的制作路径完成该区域。仅预览阶段可使用高分辨率公式图检查视觉，正式交付需检查原生数学对象。报告实际转换与验证状态。

## 数学内容校验

| 类别 | 必须核对 |
| --- | --- |
| 字母 | 大小写、希腊字母、粗体向量/矩阵、斜体变量、正体运算符 |
| 维度 | N的下标v/e/f、转置T、张量形状、行列次序、集合与索引 |
| 运算 | 乘号×与变量x、点乘、负号、加减、偏导、求和积分的上下限 |
| 分式 | 分子分母分组、分数线长度、嵌套层次 |
| 根式与括号 | 被开方范围、括号配对、括号高度覆盖全部内容 |
| 上下标 | 归属对象、同时上下标、条件和编号位置 |
| 矩阵 | 行列数量、方括号/圆括号、元素对齐、省略号方向 |
| 多行 | 等号/运算符对齐、换行是否保持语义、分段条件与对应表达 |
| 编号与说明 | 源公式编号、符号定义、变量单位和作用范围 |

不确定或来源不清的字符先回看源图或原文，记录待核项。不得凭外观补写、删改或交换科学符号。

## 视觉与密度

- 独立公式起点20—26pt，矩阵18—24pt，同行变量按所在段字号协调。显示式高度按分式和上下标实际包络增加。
- 深蓝或接近黑色T=0%，浅底保持高对比。重点变量可少量用强调红，并保留全部数学结构。
- 长式可按有意义的运算段换行，采用多行公式对齐，或将说明转到旁栏。先给公式合理宽高，再调整字号。
- 公式与来源、编号、表格边框之间留足空间。检查上方幂、下方限、长根号右端及矩阵括号。
- 高密度公式页可选“公式+符号表+几何实例”“流程+逐模块公式”“上目标函数下约束与结果”“左推导右维度对照”等组织；将数学含义、变量和对应图证充实在空区。
- 符号表中的`N_v`、`N_e`、`N_f×N_e`等涉及下标和乘法时用数学对象或当前软件支持的原生公式，保持行列居中。

## 交付关卡

1. **源式对照**。逐项核对全部变量、指数、下标、矩阵行列、运算符及编号。
2. **结构检查**。在实际PPT中确认Office数学对象或可编辑公式控件；检查包内数学元素可辅助定位。
3. **整页查看**。正常演示比例下公式可读，整体分组充实，解释与图证相邻。
4. **局部查看**。放大至150%—200%检查数学字符缺失、裁切、括号和对齐。
5. **重新打开编辑**。点入公式修改一个字符后撤回，确认编辑器仍可用，再保存最终文件。

`scripts/audit_pptx.py`可列出Office数学对象、可见字符、分式/矩阵/上下标等结构数量、含数学对象的形状尺寸，以及显式Word命名空间元素疑点。报告提供检查线索，语义正确与实际编辑行为仍需人工或当前软件验证。
